# pneumoshell — определение деформированной формы замкнутой многоярусной пневмооболочки методами машинного обучения

Программный комплекс к курсовой работе. Состоит из двух частей:

1. **Классический решатель** (`pneumoshell/solver.py`) — плоская модель поперечного сечения
   многоярусной (2–3 яруса) замкнутой пневмооболочки: нерастяжимые безмоментные мембраны
   (дуги окружностей, T = Δp·R), шарнирные узлы с балансом натяжений, адиабатическое
   изменение давления в ярусах, боковое давление воздушной подушки и обжатие
   (контакт с жёсткой опорой). Решение — демпфированный метод Ньютона с продолжением
   по параметру нагрузки.
2. **ML-модель** (`pneumoshell/ml.py`) — суррогатная модель «параметры → форма»:
   PCA-кодирование координат материальных точек + регрессор
   (MLP, гауссовский процесс, бустинг и др.). Прогноз формы — доли миллисекунды.

## Установка

```bash
python -m pip install -r requirements.txt   # numpy, scipy, scikit-learn, matplotlib
```

> Модели в `models/` сохранены scikit-learn 1.8 (Python 3.11). При другой версии
> библиотеки переобучите их: `python scripts/train_evaluate.py` (≈15 мин). Модели
> гауссовского процесса в архив не включены из-за размера (~60 МБ каждая) и
> создаются тем же скриптом.

> Датасеты (`data/*.npz`, ~20 МБ) вынесены в отдельный архив `pneumoshell_datasets.zip`:
> распакуйте его в корень проекта или сгенерируйте заново `scripts/generate_data.py`.

## Быстрый старт

```python
import numpy as np
from pneumoshell.geometry import design_two_tier
from pneumoshell.solver import ShellSolver
from pneumoshell.ml import ShapeSurrogate

# 1) классический расчёт
S = ShellSolver(design_two_tier())
sol = S.solve(p0=[6000, 6000], pc=1000, delta=0.10)   # Па, Па, м
print(sol.p, sol.contact_length)                       # давления в ярусах, длина контакта
pts = S.material_points(sol.segments)                  # координаты материальных точек

# 2) прогноз ML-моделью
sur = ShapeSurrogate.load("models/two_tier_mlp.pkl")
res = sur.predict_shape([6000, 6000], 1000, 0.10)
print(res["p"], res["contact_length"], res["points"].shape)
```

## Структура

```
pneumoshell/
  geometry.py   — дуги окружностей, конструктивные параметры оболочек
  solver.py     — классический решатель равновесия (эталон, генератор данных)
  dataset.py    — LHS-планирование и параллельная генерация выборки
  ml.py         — кодирование цели (PCA), модели, метрики, класс ShapeSurrogate
scripts/        — генерация данных, обучение, рисунки, экспорт в JSON
tests/          — модульные и интеграционные тесты
models/         — обученные модели (*.pkl)
results/        — метрики, прогнозы на тесте, сценарии апробации
figures/        — рисунки для отчёта
```

## Входные и выходные данные

| Вход | Обозначение | Диапазон |
|---|---|---|
| Давление зарядки i-го яруса | p0_i | 4–10 кПа |
| Боковое давление (давление в подушке) | pc | 0,5–2 кПа |
| Обжатие (подъём опоры от нижней точки отсчётного состояния) | delta | −0.05…0.25 м |

Выход: координаты материальных точек сечения (стенки ярусов, нижняя мембрана,
перегородки), давления в ярусах после деформации, длина зоны контакта.
